# THELIVINGSTOP Launch Countdown Theme

Standalone Shopify password theme for the 15 AUG launch.

## Setup

1. Upload THELIVINGSTOP-launch-countdown-theme.zip in Shopify Admin under Online Store > Themes.
2. Set it as the password-protected theme while the store is preparing to launch.
3. In the theme editor, confirm the launch date and timezone. The default is 2026-08-15T00:00:00+03:00.
4. The signup form uses Shopify's contact form and collects first name, last name, email, phone, and marketing consent.
5. Create the LIVING10 discount code in Shopify Admin if you want the 10% welcome offer to be redeemable.

The four launch MP4s are bundled locally in assets/ and used as the responsive visual backdrop.
