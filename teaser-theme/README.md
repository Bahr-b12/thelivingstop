# THELIVINGSTOP Pre-launch Teaser Theme

Standalone Shopify Online Store 2.0 password/teaser theme for collecting early-access leads before launch.

## Setup

1. In Shopify Admin, create a discount code named `LIVING10` with a 10% off offer and the eligibility/expiry rules you want.
2. Upload this theme under **Online Store > Themes > Add theme > Upload zip file**.
3. Set it as the password page theme while the store is pre-launch.
4. In Shopify Admin, review contact-form submissions and create a customer segment/tag for `Pre-launch early access signup`.
5. When the store launches, switch back to the full THELIVINGSTOP theme.

The theme does not process payment or shipping details. Those stay inside Shopify checkout after launch.
